# 输出标准

目标是读者能找到结论、检查依据、使用成果。以下是自有设计约定，不是对某种媒介学习效果的承诺。

## O1 · 按任务选媒介

用户指定格式时遵守指定。未指定时，选能充分完成任务、阅读和维护成本合适的形式。HTML 是载体，不是质量等级。

| 读者需要 | 通常合适 | 增加复杂度的条件 |
| --- | --- | --- |
| 获得一个事实、简短建议或状态 | 文字 | 通常无需附件 |
| 比较同维度的选项 | 表格 | 项目多或需过滤时再做交互 |
| 理解结构、依赖、流程或状态转换 | 图解配短说明 | 箭头含义明确；可用 Mermaid、UML、SVG 或 ASCII |
| 查看数量关系、分布或趋势 | 数据图配来源与口径 | 有可靠数据；推测或示意明确标识 |
| 改参数、比较情景、探索结果 | 交互页面或计算表 | 输入改变有意义的输出，模型和默认值透明 |
| 顺序阅读长报告、打印、引用页码、精确排版公式 | Markdown、文档或 TeX/PDF | 按分发和编辑需求选，保留可编辑源 |
| 观察运动、演变或操作过程 | 分段动画或视频 | 时间变化确实帮助理解，或用户明确要求 |
| 在不便看屏幕时收听解释 | 音频配文字稿 | 内容不依赖只能看懂的图表 |
| 让下游程序读取 | 现有接口规定的 JSON、CSV 等 | 遵守字段、类型、枚举和缺失值语义 |

默认给一个主要交付物。不要自动同时生成网页、PDF、幻灯片和视频。若指定媒介当前无法生成，明确说明能力限制，交付最接近的可用源文件或替代结果，不把脚本称为视频。

## O2 · 组织信息而非堆砌信息

简单任务直接回答。复杂任务先给结论、决策所需依据和关键边界，再放方法、细节或附件。内容应能独立阅读，不依赖此前进度消息。进度汇报保留有用的计数、分母和验证结果，同时说明它们对应的可用能力或关键剩余问题。条目数量不能替代对剩余工作重要性的判断，也不能凭感觉说“接近完成”。

图表也需要选对抽象层次：先说明读者要回答的问题，再选择节点、变量或坐标。删去与问题无关的细节，但保留影响判断的假设。图多、动画多、颜色多，不等于解释充分。

选择影响结论的证据，展示读者需要的理由和可复核步骤，无需输出内部思维流水账。长任务只更新新发现、重要选择或阻碍。

## O3 · 让图表可核验

流程图说明箭头代表控制流、数据流还是依赖，不混用。图中名称与正文、代码或数据一致。示意图不能伪装成实测结果。

数据图标注必要的单位、期间、来源、尺度和样本范围。保留数据与计算方式，说明缺失和不确定性。坐标截断会影响理解时明确提示；相关关系不画成未经验证的因果关系。

图解附主要结论与必要的文字说明或数据表。不要仅靠颜色表达状态。保留可修改的图源；渲染失败时提供可读替代并说明未验证渲染。

## O4 · 让交互可解释

交互必须对应读者的问题，例如“改变销量后，利润如何变化”。展示输入含义、单位、默认值、边界和计算假设；允许恢复默认状态。用一个已知结果和相关边界输入核对计算与显示。

可点击元素有明确标签，必要操作可用键盘完成。不要自动播放妨碍阅读的动画。附静态结论或导出内容，使关键结论不依赖运行脚本才能看见。

如果输出是一次性解释页面，不主动加入账户、服务器、遥测或外部发布。自包含源文件优先，但遵守现有技术栈与用户需求。平台或工具验证能力不足时，列明没验证的交互。

## O5 · 让音视频可回看

先核对脚本中的概念、因果、公式和数字，再制作画面与旁白。让画面在解释相关内容时出现，给复杂部分暂停、分段或回看的入口。

提供与内容相适应的字幕、文字稿及关键视觉说明；不要因“减少重复”取消可访问替代。具体形式按媒介和任务选择，不以本页宣称 WCAG 合规。

实际检查生成文件能否播放、画面是否可读、旁白与画面是否一致。没生成或没播放检查就说清。保留源脚本和必要资源，区分演示效果与知识正确性。

## O6 · 如实汇报交付状态（必须）

把“写好、编译通过、测试通过、上传成功、已部署、已在生产验证”当作不同事实。报告实际完成的动作、成果位置、验证范围以及影响使用的限制。

工具超时不代表失败已确认，也不代表成功；先查状态再决定是否重试，避免重复创建。不能检验某项成果时交付可用部分，同时说明缺口。仍有影响目标完成的未知或阻碍时，给出能消除它的具体下一步及必要前提，不把计划写成已执行。

研究任务给来源和证据边界；实现任务给成果和相关验证；改写任务通常直接给改写结果；只有请求审校时给修改理由。不要给所有任务套同一份大模板。

## O7 · 机器输出遵守契约（必须）

已有 schema 优先。只要用户要求纯 JSON，就不要加前言、Markdown 围栏或事后说明。无法放入额外说明时，使用已有错误或状态字段；没有这种字段且要求无法满足时，说明冲突，不偷偷添加未定义字段。

下游需要可靠状态、错误处理和来源时使用 [交接约定](handoff.md)，不要指望“语气清楚”代替数据结构。
